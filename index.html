01 · DATA ANALYTICS / MACHINE LEARNING
Python · Pandas · scikit-learnPROJETO 01

Análise de vendas — rede de farmácias

Atividade prática de preparação e exploração de uma base de vendas, construção de visualizações e comparação de modelos de classificação.

50.000registros examinados
12colunas na base original
2modelos comparados
99,99%acurácia reportada na atividade
O que foi desenvolvido
  • Inspeção dos dados, tipos, valores ausentes e duplicidades.
  • Padronização de nomes de colunas e conversão de tipos numéricos.
  • Faturamento por categoria e evolução mensal das vendas.
  • Treinamento e comparação de KNN e Árvore de Decisão, com divisão treino/teste de 70%/30%.

A acurácia de 99,99% é o resultado registrado no exercício. Como a classe de venda pode estar diretamente relacionada às variáveis usadas na previsão, o resultado deve ser interpretado no contexto didático, não como desempenho comprovado em produção.

04 · DATA ARCHITECTURE / STUDY
Arquitetura de dados · PesquisaPROJETO 04

Data Mart × Data Mesh

Estudo comparativo sobre organização de dados por área de negócio e responsabilidade distribuída entre domínios, relacionado ao dashboard automotivo.

Principais pontos
  • Data Mart: estrutura especializada para atender uma área específica.
  • Data Mesh: domínios responsáveis por seus próprios produtos de dados.
  • Exemplos de aplicação no cenário de vendas, produto, financeiro e regional.
